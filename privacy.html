TRUST & DATA PRACTICES

Privacy Policy

Icarus Personal Assistant is an experimental, independently operated personal AI research and operations project. This page describes the public informational website and the separately operated private assistant.

Last updated: November 7, 2026

Project status: This policy describes the project's intended practices. The operator must review it against the actual Icarus setup, including logging, backups, cloud providers, and connected tools, before using it for Google OAuth publication. No live Google sign-in occurs on this website.

1. This public website

The informational website contains no user account sign-up, contact form, advertising tags, or third-party analytics scripts in its published source. The site host (GitHub Pages) may collect standard technical connection information under its own policies to serve the website and maintain service security.

2. Google Calendar information

The privately operated Icarus assistant can access Google Calendar only after its account owner grants permission. Depending on granted scopes and the request, access may involve calendar names and event details such as titles, dates, times, locations, descriptions, and attendees. Icarus uses this information to answer scheduling questions and to create, update, or delete events with explicit user approval where supported. This website does not access calendar events.

3. Data storage and processing

The private assistant is intended to run primarily on operator-controlled local computers. Google authentication tokens must remain in private local storage and must never be committed to public source repositories. Calendar details may be present in local assistant conversation histories, operational logs, and backups depending on installation settings. Google maintains event data in the authorized Google account.

If external AI providers, cloud compute, or additional third-party integrations are enabled and receive Google user data, the operator must update this policy and implement applicable disclosure and consent requirements beforehand.

4. Sharing and permitted use

Icarus is intended to use Google Calendar data only to provide authorized personal-assistant services, not for targeted advertising, data brokerage, or training generalized AI models. Google data use and transfer are intended to follow the Google API Services User Data Policy, including Limited Use requirements.

5. Retention, revocation and deletion

Calendar events remain with Google until modified or deleted. Local conversations, credentials and diagnostic logs may remain until removed from the relevant application or backup. No automatic retention period is promised. The connected Google account owner can revoke authorization from Google's account security settings. Revoking authorization does not automatically erase records previously stored in local logs or backups.

6. Security

The private assistant is intended for authorized personal use and should be accessed using appropriate network and account protections. The public site is deliberately separate and does not expose credentials, private endpoints, or local network access. No system offers absolute security.

7. Changes

This document may change as the experimental assistant develops. Material changes to data practices should be disclosed here before deployment.

8. Contact

For non-sensitive questions about the public project, use the project's public GitHub issue tracker. Do not post private calendar information or credentials in a public issue. A dedicated public support email has not yet been designated.
